# 🎓 Certificate Automation Tool

This project automates the generation and distribution of certificates using **JavaScript** and **Excel/CSV** data. It reads recipient details from a CSV file, fills out a certificate template (image or PDF), and sends it via email to each participant.

---

## 🚀 Features

- Read participant details from a `.csv` or `.xlsx` file
- Fill certificate templates with dynamic data
- Generate personalized certificates (PDF/image format)
- Send certificates to email addresses automatically
- Simple, customizable, and efficient
